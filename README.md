# CPP05

## 📚 Description

CPP05 focuses on exceptions, inheritance, and polymorphism.

The exercises introduce how to design robust C++ classes using exception handling, abstract classes, interfaces, and polymorphic behavior.

## 🧠 Key Concepts
- Exception handling: try, catch, and throw
- Custom exception classes
- Inheritance
- Base and derived classes
- Virtual functions
- Polymorphism
